# AI News Summarizer

An automated AI-powered news summarization workflow built using n8n and Google Gemini.

## Workflow Screenshot

![AI News Summarizer Workflow](https://github.com/user-attachments/assets/4483b68d-e069-45df-96c3-0c6485191fbc)

## Features

- Fetches news articles from RSS feeds
- Aggregates news from multiple sources
- Uses Google Gemini to summarize news
- Organizes news into categories
- Generates concise and readable summaries
- Sends the summarized news via email

## Technologies Used

- n8n
- Google Gemini
- Generative AI
- Prompt Engineering
- RSS Feeds
- Gmail
